# Unix Epoch Timestamp, Date & Timezone Studio — Gamility Tools

A modern, comprehensive developer utility for Unix timestamps, UTC/GMT dates, ISO 8601 formatting, multi-timezone world comparisons, and programming snippet generators.

---

## 🌟 Features & Highlights

- **⏱️ Live Epoch Clock:** Real-time pulse display of the current Unix timestamp in Seconds (10 digits) and Milliseconds (13 digits) with live pause/resume and 1-click clipboard copy.
- **🔄 Two-Way Conversion Engines:**
  - **Timestamp &rarr; Human Date:** Converts any epoch timestamp (seconds or milliseconds auto-detected) into UTC/GMT, ISO 8601, RFC 2822, Local Date & Time (with UTC offset), relative time (*e.g., 2 hours ago*), Day of Week, Day of Year, and Leap Year status.
  - **Human Date &rarr; Timestamp:** Select custom Date (`YYYY-MM-DD`), Time (`HH:mm:ss`), and Timezone to instantly generate Epoch Seconds, Milliseconds, and Hexadecimal representations.
- **🌍 Multi-Timezone World Clock:** Simultaneous real-time conversion across major international financial and developer hubs:
  - UTC / GMT
  - New York (EDT / EST)
  - London (BST / GMT)
  - Mumbai (IST)
  - Tokyo (JST)
  - Sydney (AEST / AEDT)
- **💻 Programming Language Snippets:** 1-click syntax copies for getting current timestamps across JavaScript, Python, PHP, Go, Java, C#, and SQL.
- **⏳ Date Difference Calculator:** Calculate exact elapsed duration between two timestamps or calendar dates (Days, Hours, Minutes, Seconds).
- **🔒 100% Client-Side Privacy:** Zero server transmissions. All calculations and timezone mappings execute strictly in your local browser memory.

## 🚀 Quick Start

### Local Preview
Open `index.html` directly in any modern browser:
```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

Or serve via any static HTTP server:
```bash
npx serve .
```
